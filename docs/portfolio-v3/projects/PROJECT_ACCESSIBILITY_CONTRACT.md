# Project Accessibility Contract — S2-PRE

Target: **WCAG 2.2 AA** · Lighthouse Accessibility 100 where feasible.

---

## Global

- Full keyboard operation · visible focus · logical focus order  
- Contrast AA · touch targets ≥24×24px (prefer 44×44 where primary)  
- `prefers-reduced-motion`: static final states  
- No hover-only content · no drag-only discovery  
- Status labels not color-only  

---

## Selected Systems

- Region + accessible name  
- H2 chapter / H3 projects  
- Flagship and supporting CTAs reachable without pointer  
- Diagrams have text alternatives  
- Motion optional; content available immediately under reduced motion  

---

## Systems Atlas

- Search field labelled; results count in live region (polite, throttled)  
- Filters as fieldset/group with legends  
- Combos announced once after settle, not per keystroke  
- Empty state actionable  
- Project previews are links or contain a clear link  

---

## System Dossier

- Skip link to main content  
- In-page anchors for major blocks when present  
- Gallery: keyboard, captions/alts, no autoplay video with sound  
- Diagrams: text alternative adjacent or linked  

---

## Version switch (existing)

Remains a development utility — not part of public portfolio a11y narrative, but must stay keyboard accessible while enabled.
